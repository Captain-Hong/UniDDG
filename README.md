# UniDDG
This is an open-source code repository prepared for paper "Rethinking domain generalization in medical image segmentation: One image as one domain". https://arxiv.org/abs/2501.04741

Two datasets are publicly available at:
https://drive.google.com/file/d/1xb00zAzWP1tnWybVBUBn2Wmkbv6yYMqY/view?usp=sharing 
Folders D1, D2, D3, and D4 contain data files from four different centers of the optic cup‑optic disc dataset.
Folders Da, Db, Dc, Dd, and De contain data files from five different centers of the prostate dataset.
Unzip the dataset archive directly and place the extracted files in the same directory as the main program for execution.
